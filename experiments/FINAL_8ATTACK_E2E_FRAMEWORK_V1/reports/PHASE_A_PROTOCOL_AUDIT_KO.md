# Phase A — 8개 공격 프로토콜 감사

성능 숫자를 보기 전에 원 쿼리·원 점수식을 복구할 수 있는지를 먼저 판정했다.

| 공격 | 판정 | 실제 생성 가능 여부 |
|---|---|---|
| MEntA | PAPER_PROTOCOL_READY | READY_EXISTING_IMMUTABLE_QUERIES |
| MBA | PAPER_PROTOCOL_READY | READY_EXISTING_IMMUTABLE_QUERIES |
| RAG-MIA | PAPER_FAITHFUL_REIMPLEMENTATION | READY_EXISTING_IMMUTABLE_QUERIES |
| S²-MIA | PAPER_FAITHFUL_REIMPLEMENTATION | READY_TO_BUILD_ON_SHARED_TARGETS |
| DCMI | PROTOCOL_UNAVAILABLE | BLOCKED_NO_IMMUTABLE_PERTURBATION_BUNDLE_AND_NO_API_CREDENTIAL |
| IA | PROTOCOL_UNAVAILABLE | BLOCKED_ORIGINAL_GT_BUNDLE_NOT_RECOVERED |
| RAGLeak | PROTOCOL_UNAVAILABLE | BLOCKED_EXACT_CROP_PROMPT_AND_SCORER_NOT_RECOVERED |
| BudgetLeak | PROTOCOL_UNAVAILABLE | BLOCKED_SHARED_BEIR_TARGETS_HAVE_NO_PAIRED_QA_REFERENCES_AND_AUTHOR_SCORER_NOT_RECOVERED |

DCMI·IA·RAGLeak·BudgetLeak에는 임의 대체 점수를 넣지 않는다. 나머지 공격의 실행은 계속한다.
